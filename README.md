# Idle Game

This is the server for the Idle Game project [Idle Game](https://github.com/AlfredAbdo/IdleGame). It only saves your progress, as this was
my test for a Ktor project.

Idle Game can run as an Android app on its own without the server being up, but your data data will be local to the app. For now, this
server can only be used locally (localhost:8080) with the Idle Game project running on the same device.
